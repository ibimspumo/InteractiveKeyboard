## Interactive Keyboard v0.1.0 — Erstes Release

Erstes öffentliches Release des Interactive Keyboard Overlays für TikTok-Streamer.

### Features

- **Transparentes Overlay** (Windows, 1:1 Aspect-Lock) — perfekt für OBS-Capture
- **Konfigurierbare Tastatur** — Standard-Layout WASD + Space, beliebig erweiterbar
- **Webhook-API** (`/block`, `/unblock`, `/reset`, `/status`, plus Kurzform `/w?duration=…`) zum Steuern aus externen Tools / Bots
- **Systemweite Tasten-Blockierung** via Win32 Low-Level Keyboard Hook (`WH_KEYBOARD_LL`)
- **Visuelles Feedback**: rotes X + Countdown auf gesperrten Tasten
- **Mehrfach-Trigger-Modi**: `add` (Restzeit aufaddieren, gekappt), `reset` (überschreiben), `ignore` (verwerfen)
- **Anti-Cheat-Schutz**: Block-Requests werden stillschweigend verworfen, solange ein erkannter Anti-Cheat-Prozess läuft (Valorant, Fortnite, R6 etc.)
- **Design-Modus (`D`)**: Stil-Editor pro Taste — Farben, Form, Schrift, Effekte
- **Edit-Modus (`E`)**: Gift-Icon-Positionierung per Drag (mit TikTok-Gift-Library)
- **Sounds**: Burst-fester Audio-Pool für Block-/Unblock-Sounds, eigene Sounds zuweisbar
- **Auto-Update**: Updater-Plugin mit minisign-Signatur, sucht automatisch auf GitHub Releases
- **Persistenz**: Settings werden in `%APPDATA%/de.agentz.interactivekeyboard/settings.json` gespeichert
- **App-Sprache**: Deutsch

### Installation

- **Windows**: `.exe`-Installer (NSIS) aus den Release-Assets herunterladen und ausführen
- SmartScreen-Warnung kann auftreten (kein Code-Signing-Zertifikat) — „Weitere Informationen" → „Trotzdem ausführen"

### Konfiguration

- `ESC` öffnet das Settings-Panel
- Webhook-Server läuft per Default auf Port `8080` (localhost only). In den Settings auf „alle Interfaces" umstellbar.
- Multi-Trigger-Modus und max. Block-Dauer in den Settings einstellbar

### Auto-Update

Ab dieser Version aktiv. In bestehenden Installationen: `ESC` → Tab „Updates" → „Nach Updates suchen".

### Bekannte Einschränkungen

- Windows-only (Win32-Hook-API)
- Kein Code-Signing → SmartScreen warnt beim ersten Start
