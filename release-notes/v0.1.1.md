## Interactive Keyboard v0.1.1

Kleines Folge-Release mit einer optionalen Einstellung rund um den Anti-Cheat-Schutz.

### Features

- **Anti-Cheat-Schutz umschaltbar**: Neue Option unter „Einstellungen → Block-Verhalten → Anti-Cheat-Schutz". Standardmäßig **aktiv** (= bisheriges Verhalten). Deaktivieren lässt sich der Schutz für Szenarien, in denen man bewusst Tasten blocken will, während ein Anti-Cheat-Prozess läuft.

### Wichtiger Hinweis

Der Schutz existiert aus gutem Grund: Die App nutzt einen Low-Level Keyboard Hook, der von Anti-Cheat-Systemen (Vanguard, EAC, BattlEye, …) als verdächtig eingestuft werden kann. Wer den Schutz abschaltet und gleichzeitig kompetitive Online-Shooter spielt, riskiert einen Account-Bann. Im Zweifel: **anlassen**.

### Sonstiges

- Bestehende Configs werden automatisch migriert (Schutz bleibt eingeschaltet).
- Keine Webhook-API-Änderungen, kein Breaking.
